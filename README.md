# Soundarya T J — Personal Portfolio

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and the `assets/` folder together.
2. Open `index.html` in a web browser.

## Project structure
- `index.html` — page content and section structure.
- `style.css` — theme, layout, responsive styles, and animations.
- `script.js` — small interactive behaviours (footer year and reveal-on-scroll).
- `assets/` — profile photo and organisation/college logos.

## Make changes
- Change text, headings, links, and sections in `index.html`.
- Change colours, spacing, typography, and responsive layout in `style.css`.
- Add or modify interactive behaviour in `script.js`.
- Keep image filenames in `assets/` the same as their references in `index.html`, or update the relevant `src` path when replacing an image.

## Publish with GitHub Pages
Upload the contents of this folder (including all three source files and the entire `assets/` folder) to the root of a public GitHub repository, then enable Pages from `Settings → Pages → Deploy from a branch → main → /(root)`.
